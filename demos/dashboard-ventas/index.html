¿Cómo funciona? ✿

Tres piezas que trabajan juntas: una base de datos, un simulador que hace de "tienda" y el panel que lo cuenta todo.

  • PostgreSQL guarda cada venta en la tabla sales_data (producto, ciudad, cantidad, importe y fecha) — el esquema completo está incluido más abajo.
  • simulate_sales.py actúa como la caja de una tienda: cada minuto inserta una venta aleatoria en la base de datos, para poder ver el panel moviéndose en directo.
  • Streamlit + Pandas consultan las últimas 100 ventas con una caché de 60 segundos, y el panel entero se refresca solo cada minuto (además del botón de refresco manual).
  • Plotly dibuja las gráficas interactivas: barras de ventas por producto coloreadas por ciudad y quesito con la distribución por ciudad.
  • El tema visual está hecho con CSS personalizado inyectado en Streamlit: tarjetas de métricas con degradados, tipografía y botones a juego.

▶ Pruébalo en tu ordenador

  1. Crea una base de datos PostgreSQL y ejecuta esquema.sql para crear la tabla con datos de ejemplo.
  2. Pon tus credenciales en la cadena de conexión de dashboard_app.py y simulate_sales.py.
  3. Instala las dependencias y arranca el panel:
pip install streamlit pandas plotly sqlalchemy psycopg2-binary
streamlit run dashboard_app.py
Opcional: ejecuta python simulate_sales.py en otra terminal para ver el panel actualizarse solo con ventas nuevas.
